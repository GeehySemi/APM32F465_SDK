# APM32F465_SDK
Official software development kit for Geehy APM32F465 microcontrollers.

## Current version

- SDK version: V1.0.0
- Supported device: APM32F465
- Official package date: January 3rd, 2023
- Release notes date: October 27th, 2026
- Official download: [APM32F465_SDK_v1.0.zip](https://www.geehy.com/uploads/tool/APM32F465_SDK_v1.0.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
